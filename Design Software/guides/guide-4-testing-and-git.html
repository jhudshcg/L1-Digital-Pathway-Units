💾 2. Using Git in VS Code (AC 1.7)

Git creates saved checkpoints (called commits) of your project as you work. You do not need to type command line codes — you will use the visual Source Control button inside VS Code.

Step 1: One-Time Git Identity Setup (Terminal)

If you have not configured Git before on your college computer, open the VS Code Terminal and run:

git config --global user.name "Your Full Name"
git config --global user.email "your.student.email@college.ac.uk"
Step 2: Committing Your Work via the VS Code GUI
  1. Click the Source Control icon in the left sidebar of VS Code (or press Ctrl + Shift + G).
  2. Look at your changed files under Changes.
  3. Click the + (Plus icon) next to Changes to "Stage All Changes".
  4. In the message box at the top, type a clear commit message describing what you just completed.
  5. Click the blue Commit button (or press Ctrl + Enter).
Good Commit Message Examples:
  • "feat: added 10 researched food items and local images"
  • "style: applied 50s diner theme and Google Fonts"
  • "feat: completed subtotal calculation and £5.50 voucher check"
  • "fix: corrected allergen warning text for dairy products"
