Test your canteen system, fix any issues, and save your progress using Git in VS Code.

2. Using Git in VS Code (AC 1.6, 1.7)

Git allows you to save snapshots ("commits") of your project milestones. You do not need to use the command line — you will use the VS Code Source Control panel.

Step 1: One-Time Git Identity Setup (Terminal)

If you have not set up your name in Git before, open the terminal in VS Code and type:

git config --global user.name "Your Full Name"
git config --global user.email "your.student.email@college.ac.uk"
Step 2: Committing Your Work via the VS Code GUI
  1. Click the Source Control icon in the left sidebar of VS Code (or press Ctrl + Shift + G).
  2. Review your changed files under Changes.
  3. Click the + (Plus icon) next to Changes to "Stage All Changes".
  4. In the message box at the top, type a meaningful commit message explaining what you just completed (see examples below).
  5. Click the blue Commit button.
Good Commit Message Examples:
  • "feat: added 10 researched menu items and image links"
  • "style: applied retro diner theme and Google Fonts"
  • "feat: completed subtotal calculation and £5.50 voucher check"
  • "fix: corrected allergen warning text for dairy products"

3. Collecting Your Project Booklet Evidence

Before submitting, make sure you take clear screenshots of:

  • Your finished Canteen UI running in the browser.
  • Your Git commit history list in VS Code.
  • Your completed JavaScript code in app.js.
