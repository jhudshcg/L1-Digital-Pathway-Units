🧠 1. What is JavaScript? (Beginner Friendly Intro)

JavaScript is the programming language that gives your canteen app its intelligence. While HTML displays the cards and CSS makes them look great, JavaScript does the math calculations, checks meal voucher budgets, and alerts users about allergies.

📦 Variables (var)
Labelled storage boxes that hold information, such as numbers (price: 3.50) or text (name: "Burger").
🔄 Loops (for)
A repetition machine that looks at every item on the user's tray, one by one, to add up prices or check allergies.
⚖️ If Conditions (if)
Decision makers that ask True/False questions (e.g. "Is the total over £5.50?" or "Does this item contain nuts?").
⚙️ Functions
A named recipe or mini-program that performs a specific job and gives back an answer (like calculating the total to pay).
Your Workspace Setup: All your coding tasks are inside app.js. The other script file, util.js, handles background screen updates — you do not need to touch util.js!

for (var i = 0; i < items.length; i++) {
  total += items[i].weight; // Adds each item's weight to the total

🤔 Which code line should replace total += 0; inside calculateSubtotal(tray)?
Option A: total += tray[i].name; — (Adds item names together as text)
Option B: total += tray[i].price; — (Adds each item's price to the running total)
Option C: total += items[i].weight; — (Uses 'items' instead of 'tray' and 'weight' instead of 'price')
Option D: total = total + 5.50; — (Always adds a fixed £5.50 regardless of items)

In app.js: Inspect the function calculateSubtotal(tray), pick the correct option, replace total += 0;, save with Ctrl + S, and add items in your browser to verify that the subtotal updates!

Challenge 2: £5.50 Meal Voucher Budget Check
Fill-in-the-Blank

Goal: If the student's order exceeds the £5.50 meal voucher limit, trigger a warning message.

In app.js, find the checkBudgetLimit(totalAmount) function:

function checkBudgetLimit(totalAmount) {
  var voucherLimit = 5.50;

  // Which operator should replace '==' ?
  if (totalAmount == voucherLimit) {
    return "Warning: Your order of £" + totalAmount.toFixed(2) + " exceeds the £5.50 meal voucher limit!";
  }
  return "";
}
🤔 How do comparison operators work with numbers?
Option A: > — Greater Than: Left side is BIGGER than right side.
Example: 6.20 > 5.50 is TRUE (and totalAmount > voucherLimit triggers warning when over budget)
Option B: < — Less Than: Left side is SMALLER than right side.
Example: 4.50 < 5.50 is TRUE (triggers when under budget)
Option C: == — Equal To: Both sides must be EXACTLY the same.
Example: 5.50 == 5.50 is TRUE (triggers only if total is exactly £5.50)
Option D: + — Plus Sign: Adds two numbers together (Math arithmetic, not a True/False comparison test)

🔍 4. How to Test & Debug Your Code (Developer Tools)

Spotting Mistakes: If a button doesn't work or totals don't update:
  1. Open your app in the browser (Chrome / Edge).
  2. Press F12 (or right-click and choose Inspect).
  3. Click the Console tab at the top.
  4. Look for any red error messages — the console will tell you the exact line number in app.js where a spelling or syntax mistake occurred!
