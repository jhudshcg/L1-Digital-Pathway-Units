JavaScript Coding Challenges & Snippet Bank

Complete the interactive logic in app.js using fill-in-the-blanks and the snippet bank.

1. Understanding app.js vs util.js

In this project, your code is cleanly split:

  • util.js: Contains background helper functions that build cards on the screen and listen for button clicks. Do not edit this file.
  • app.js: Contains your menu item data and the 5 specific functions you will complete. You will do all your coding here!

2. Step 1: Inputting Your Menu Research

Open app.js and look at the orderItems list. Each food item is an object with properties:

var orderItems = [
  {
    name: "Classic Chicken Burger",
    price: 3.50,
    image: "https://your-image-url.jpg",
    type: "main",                  // "main", "snack", or "drink"
    description: "Crispy breaded fillet with fresh lettuce and mayo.",
    healthpromo: false,             // true for healthy, false otherwise
    alergy_warning: ['gluten', 'dairy']
  },

3. The 5 Coding Challenges

Challenge 1: Calculate Order Subtotal (Snippet Bank)

Goal: Add up the price of every item currently sitting in the user's tray.

Snippet Bank Reference:

var total = 0.0;
for (var i = 0; i < tray.length; i++) {
  total += tray[i].price; // Adds each item price to total
}
return total;

In app.js: Find calculateSubtotal(tray) and replace total += 0; with total += tray[i].price;.

Challenge 2: Meal Voucher Budget Check (Fill-in-the-blank)

Goal: If the student's order exceeds the £5.50 meal voucher limit, display a warning message.

Comparison Operators:

  • > means "is greater than"
  • < means "is less than"
  • === means "is exactly equal to"

In app.js: Find checkBudgetLimit(totalAmount) and change the comparison so it checks if totalAmount > voucherLimit.

Challenge 3: Allergen Alert (Fill-in-the-blank)

Goal: Alert the user if any item on their tray contains 'nuts' (or another allergen).

if (item.alergy_warning.includes('nuts')) {
  return "Allergy Alert: " + item.name + " contains nuts!";
}

In app.js: Find checkOrderAllergies(tray) and replace BLANK_ALLERGEN with 'nuts'.

Challenge 4: Healthy Choice Promotion Discount (Snippet Bank)

Goal: If a customer picks 2 or more healthy items, give them a 10% discount on their subtotal.

Snippet Bank Reference:

var healthyCount = 0;
for (var i = 0; i < tray.length; i++) {
  if (tray[i].healthpromo === true) {
    healthyCount += 1;
  }
}
if (healthyCount >= 2) {
  return subtotal * 0.10; // 10% discount amount
}

In app.js: Complete the counter in checkHealthyPromotion() and return subtotal * 0.10.

Challenge 5: Custom Checkout Confirmation Message

Goal: When the user clicks "Place Order", give them a friendly message confirming how many items they ordered.

function handleCheckout(tray) {
  var customerMessage = "Order Placed! Thank you for ordering " + tray.length + " item(s).";
  updateFeedback(customerMessage, "success");
}
