Understand how web pages work, how CSS classes style HTML elements, and customize your app's visual identity.

🏗️ 1. The 3 Building Blocks of a Web App

Every website and web application is built using three essential languages that work together as a team:

🦴
HTML
The Skeleton / Structure
Places the building blocks on the page: headings, text, buttons, images, and card boxes.
🎨
CSS
The Clothes / Style
Paints the look and feel: colours, backgrounds, fonts, borders, card layout, and spacing.
⚡
JavaScript
The Brain / Action
Makes it interactive: calculates order totals, checks budget vouchers, and displays allergy alerts.

🏷️ 2. What is an HTML Element and a CSS Class?

1. What is an HTML Element?

An HTML element is a building block on a page. It starts with an opening tag <tag>, has some content inside, and finishes with a closing tag </tag>:

<h1>Campus Canteen</h1>       <!-- Heading Element -->
<button>Place Order</button>  <!-- Button Element -->

2. What is the <body> Element?

The <body> tag is the master container that wraps around everything visible on the screen. Any style applied to the <body> changes the overall look of the entire page.

3. What is a CSS Class Attribute?

A class is like a label or a costume tag attached to an HTML element. When you write class="..." inside a tag, CSS checks its rulebook in style.css and instantly applies that design theme:

<!-- Giving the body element 4 style classes: -->
<body class="layout-grid colour-light theme-modern spacing-standard">

🧪 3. Hands-On Activity: Test Changing a Style Class

🎯 Step-by-Step Practice:
  1. Open your project folder in VS Code.
  2. Open the index.html file.
  3. Look around line 18 for the <body class="..."> tag.
  4. Change colour-light to colour-dark: 
    <body class="layout-grid colour-dark theme-modern spacing-standard">
  5. Save the file by pressing Ctrl + S.
  6. Double-click index.html (or refresh your browser tab) — notice how the app instantly flips to a dark night-mode colour scheme!
  7. Now try changing theme-modern to theme-americana or theme-punk, save, and refresh to see the typography and borders change!
