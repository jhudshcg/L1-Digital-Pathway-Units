Customising Styles & Layout

Discover how to instantly change the theme, fonts, colours, and card arrangement by editing class names in index.html.

1. How Class-Based Theming Works

Your starter template uses powerful CSS classes. By adding or changing 4 simple class names on the <body> tag in index.html, you can completely restyle your canteen app without touching complex CSS code!

<!-- Open index.html and find line 18: -->
<body class="layout-grid colour-light theme-modern spacing-standard">

4. Stretch Challenge: Customising Colours & Google Fonts

If you want to customise your colours even further, open style.css and look at the top section under :root:

/* In style.css, try changing these hex colour codes: */
:root {
  --color-primary: #2563eb;       /* Main button colour */
  --color-primary-hover: #1d4ed8; /* Button hover colour */
  --bg-header: #1e293b;           /* Header banner background */
}
Pro Tip: Use fonts.google.com to browse new fonts, copy the <link> code into your index.html <head>, and set --font-heading: 'YourFontName'; in your CSS!
