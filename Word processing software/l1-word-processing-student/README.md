## 🚀 Project Summary
* **Goal:** Create a structured **5+ page guide or report** on a favourite interest (e.g. video game, sport, hobby, music artist, vehicle).
* **Key Requirements:**
  1. Minimum 5 pages length
  2. Cover Page with Title, Subtitle, Artwork, and Learner Name
  3. Automated Table of Contents on Page 2
  4. Consistent Heading Hierarchy (`Heading 1`, `Heading 2`)
  5. 12pt body text with proper paragraph spacing
  6. At least one styled Table with visible cell borders
  7. At least one styled Callout Text Box
  8. Live external hyperlink
  9. Running Header on Page 2+ and `Page X of Y` in the Footer
  10. Saved as `.docx` and exported to `.pdf`
