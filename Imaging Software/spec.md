# Imaging Software — R/505/3062

- **Status:** Draft for teacher review, 6 November 2026.
- **Level:** 1
- **Credits:** 3
- **Guided learning hours (GLH):** 20
- **Software:** Adobe Photoshop on Windows desktop; check menu labels in the college installation before delivery.

## Unit aim

Obtain and combine images and text for a purpose. Use imaging tools to create, edit and improve a design, then save and retrieve suitable files for editing, print and screen use.

This is a plain-language teaching aim. The assessment criteria below retain the wording supplied in the original unit specification.

## Project: Make a poster for Kickstart

Create a poster advertising Kickstart, the course the students are on. Help a prospective student understand what they could make or learn. Showcase some of your own work and work by somebody else, with permission where needed. Use Photoshop to combine the material into your own design.

Follow [AGENTS.md](../AGENTS.md) for the audience, scaffolding and shared booklet layout. Students keep work in their own college OneDrive Imaging Software folder, outside the resource repository. They do not need Git or a code editor.

### Draft brief and output settings

These are practical starting assumptions, not additional qualification criteria. The teacher may adjust them before delivery; update the guide, booklet and starter brief together.

| Item | Draft requirement |
| :--- | :--- |
| Audience | Prospective Kickstart students, aged 16+ |
| Purpose | Show what students make and encourage the reader to find out more |
| Print context | A4 portrait poster for a college noticeboard |
| Screen context | Smaller copy for a college information page; submit to the teacher rather than publish |
| Working document | 210 × 297 mm, 300 pixels/inch; approximately 2480 × 3508 pixels; RGB, 8-bit, sRGB |
| Print copy | High-quality JPG at original pixel dimensions; retain/check 300 ppi and A4 dimensions |
| Web copy | JPG or PNG, 1000 pixels wide, proportional height approximately 1415 pixels; sRGB |
| Safe spacing | Keep important words and pictures at least 10 mm from the edge; no bleed required for this classroom draft |
| Course information | Course name, two short teacher-checked course facts and a teacher-approved next step/contact route |

For a professional print supplier, obtain their specification before changing colour mode, bleed or outputs. Web size is controlled by pixel dimensions; changing only a ppi number does not make the image smaller.

### Core project requirements

- A clear Kickstart title, two accurate course facts and a useful next step for the reader.
- At least one image of the student's own work and one image of somebody else's work. Use teacher-approved material and record its source, permission and any required credit.
- A short plan identifying audience, purpose, image needs and print/screen contexts.
- A PSD with named layers and at least one layer group; retain editable text and an editable mask.
- Imported images as separate layers, sensible resizing and placement, a selection and a refined layer mask.
- A brush used on a separate layer to create a useful design element, with a deliberate choice of brush type, size and opacity.
- A suitable filter applied as an editable Smart Filter, with a brief reason. Avoid effects that make the showcased work unclear or misleading.
- A review using Photoshop tools and reader feedback; record two useful improvements and correct other problems found.
- A saved PSD that the student can locate and reopen, plus checked print and web copies.
- A completed assessment booklet, including source records and focused evidence.

Judge achievement against the assessment criteria, not the number of effects or decorative complexity. Offer support without removing criteria. Supplied practice illustrations are for learning tools; they do not replace the final poster's requirement to show the student's own work and somebody else's work.

### Optional extensions

After the core work: adjustment layers, more precise edge refinement, a second layout for a different screen shape, or comparison of export formats. Keep the assessed work achievable within six to seven weeks.

## Assessment criteria from the qualification specification

### 1. Be able to obtain, insert and combine information for images.

1.1. Identify what images are needed.

1.2. Obtain, input and prepare images to meet needs.

1.3. Identify what generic copyright and other constraints apply to the use of images.

1.4. Combine information of different types or from different sources for images.

1.5. Identify the context in which the images will be used.

1.6. Identify which file format to use for saving and exchanging images.

1.7. Store and retrieve files effectively, in line with local guidelines and conventions where available.

### 2. Be able to use imaging software tools to create, manipulate and edit images.

2.1. Use suitable tools and techniques to create images.

2.2. Use appropriate tools and techniques to manipulate and edit images.

2.3. Check images meet needs, using IT tools and making corrections as necessary.

## Booklet tasks/activities with assessment criteria mapping

This defines the draft sequence. Guide steps and booklet tasks use the same numbers. Update this plan before changing tasks in either resource.

### Introductory practice: Step 0 — Try, save and reopen

- **Activity:** Open a supplied practice image, create a small two-image composition, try Move and Undo, and save/reopen a PSD. Use teacher demonstration and a quick understanding check.
- **Evidence:** Informal demonstration; no separate assessed written response. Revisit retrieval in Task 8.
- **Mapping:** Diagnostic practice, not a separate assessed task.

### Task 1: Plan your message

- **Activity:** Explore the annotated layout example and starter brief. Identify reader, purpose and two use contexts. Choose work to show and sketch a layout with headline, images, course facts and next step.
- **Evidence:** Short planning notes, labelled layout sketch and image-needs list with reasons.
- **Mapping:** AC 1.1, 1.5.

### Task 2: Gather and check your images

- **Activity:** Obtain images of own work and another person's work; keep originals. Record sources, permission/licence and credits. Identify an additional constraint such as a person's consent, private information, file quality or branding rules. Prepare usable copies and check pixel dimensions and sharpness.
- **Evidence:** Source/permission log, short explanation of a constraint and action, image preparation note, original and working files. Teacher can observe obtaining/inputting images.
- **Mapping:** AC 1.2, 1.3.

### Task 3: Build your poster with layers

- **Activity:** Create the A4 document, place images, resize without stretching and combine them with original text and a background. Name layers, create a group and arrange the order so information is clear.
- **Evidence:** PSD; focused screenshot showing the composition and readable layer names/group; short note naming the combined sources/types.
- **Mapping:** AC 1.4, 2.1.

### Task 4: Select and mask

- **Activity:** Choose an area to keep, make a selection, add a layer mask and improve its edge with black/white brush strokes. Keep original image data so the change can be reversed.
- **Evidence:** Before/after snippets, readable mask thumbnail and short note describing the selection tool and edge correction; editable PSD mask.
- **Mapping:** AC 2.2.

### Task 5: Create and refine details

- **Activity:** Compare hard/soft brushes in practice, then choose a brush and settings for a useful element on a separate layer. Apply a suitable Smart Filter to an image/background layer and adjust its strength. Retain editable type and check text hierarchy.
- **Evidence:** PSD; focused brush-layer and Smart Filter screenshots; brief choice/reason records. Demonstration can supplement brush-setting evidence.
- **Mapping:** AC 2.1, 2.2.

### Task 6: Review and improve

- **Activity:** Use Fit on Screen and 100% zoom, check image size and text, inspect edges and spacing, and get peer/teacher feedback. Make two useful improvements with Photoshop tools; continue fixing other issues.
- **Evidence:** Reviewer name and suggestion, two before/tool/after records, improved PSD and brief tool-based quality checks.
- **Mapping:** AC 2.3.

### Task 7: Choose formats and make copies

- **Activity:** Explain the roles of PSD and selected JPG/PNG outputs. Save a print copy at original size, then export a smaller web copy without shrinking the PSD. Reopen both and check dimensions, colour and readability.
- **Evidence:** Student's own format reasons, output settings/check record, actual PSD and two image files. Include a focused Image Size screenshot for the reopened print copy.
- **Mapping:** AC 1.6, 2.3.

### Task 8: Retrieve and hand in

- **Activity:** Close and locate/reopen the PSD from the correct folder, demonstrate an editable layer and save. Use the final checklist; if anything changes, regenerate and check both outputs. Submit the booklet and project files.
- **Evidence:** File locations/names, dated teacher observation of retrieval, final checklist, brief reflection and submitted files.
- **Mapping:** AC 1.7. The final checklist also confirms completion of earlier evidence.

### Assessor record and student declaration

Record all ten criteria individually, with evidence locations, further action and dated observations where useful. Record a Pass/Resubmission decision, assessor name, signature and date. End with the learner authenticity declaration, checkbox, name, ID, date and signature.

## Evidence and submission

Students use their own Imaging Software folder with these subfolders:

- `originals`: unchanged source files; retain locally for assessment checks.
- `working`: `Firstname-Surname-Kickstart.psd`.
- `exports`: `Firstname-Surname-Kickstart-print.jpg` and `Firstname-Surname-Kickstart-web.jpg` (or `.png` for web).
- `evidence`: completed booklet and any additional evidence snippets.

Submit the PSD, both outputs and completed booklet through the teacher's class hand-in location. Keep originals and permission records available to the assessor; include originals in submission only where the teacher's instructions and reuse permissions allow. Do not publish course posters or images of other learners independently.

## Teacher preparation and draft decisions

Before delivery:

1. Confirm audience, A4 brief, web dimensions, software version and submission route. Replace draft settings consistently if needed.
2. Supply two accurate Kickstart facts and an approved next step/contact route; confirm branding rules. Examples contain no invented dates, fees, promises or contacts.
3. Arrange suitable images of each student's own work and another person's work. Check permission for the intended use, including any people shown; allow an alternative if permission is unavailable.
4. Select booklet artwork. The current neutral image is a temporary space holder, not teacher-approved cover art. Replace `src/booklet_cover.png` and regenerate.
5. Check Photoshop steps on a college machine; add genuine interface screenshots if useful. The guide supplies labelled concept diagrams, not imitation application screenshots.
6. Check rendered cover, complete criteria page and evidence spaces. The draft was rendered to 18 pages with all criteria on page 2; the PDF preview is for review, not student data entry. Verify the header reads Imaging Software (R/505/3062), credit is 3 and page fields update.
7. Complete repository setup after the first human-created student-repository commit. Keep all commits under teacher control; see the student README for the handoff.
