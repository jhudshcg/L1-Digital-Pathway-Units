Git Version Control & Testing Guide

Unit R/505/1688 - Learn how to track changes, save versions, and test your multimedia page across devices.

1. Why Use Git for Your Multimedia Project?

Git is like a high-powered "Save Game" system for web developers and multimedia designers. It records checkpoints (called commits) every time you complete a task or make a change to the page you're happy with.

  • Safety: If something breaks or an image doesn't display, you can see what changed and restore working code.
  • Evidence: Your Git history proves that you built the project step-by-step (meeting assessment criteria AC 2.5 & 2.6).
  • Easy in VS Code: You do NOT need complex terminal commands—you can use the built-in VS Code Source Control button!

2. Making Commits in VS Code (2 Simple Steps)

Step 1: Open the Source Control Tab

Click the Source Control icon on the left sidebar of VS Code (or press Ctrl + Shift + G). You will see the files you edited listed under Changes.

Step 2: Type a Message & Click Commit

Type a short description of what you did in the Message box, then click the blue Commit button (or press Ctrl + Enter).

(If VS Code asks to save/commit all changes, click "Always" or "Yes".)

Good Commit Message Examples:
  • Add initial pet hero header and nature theme
  • Import 4 cropped gallery photos into images folder
  • Embed action video with native HTML5 controls
  • Add accordion care guide and test responsive layout

3. Cross-Device Responsive Testing (AC 4.1 & 4.4)

Your webpage must adapt cleanly to different screen sizes, including desktop monitors, tablets, and mobile phones.

How to Test Screen Sizes with Browser DevTools:

  1. Open your index.html in Microsoft Edge or Google Chrome.
  2. Press F12 (or right-click and choose Inspect).
  3. Click the Toggle Device Toolbar icon (or press Ctrl + Shift + M).
  4. Select different devices from the top dropdown (e.g. iPhone SE, iPad Air, Desktop 1080p).
  5. Check that text doesn't overlap, images scale cleanly, and videos remain fully usable.
