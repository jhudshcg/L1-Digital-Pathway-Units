Customising Styles, Layout & Media Tags

Unit R/505/1688 - How to change CSS theme classes, embed video controls, and customize your webpage layout.

1. The Power of CSS Class Customisation

You can completely transform the design, typography, and mood of your webpage without rewriting complex CSS. Simply change the class names on the <body> tag in index.html!

<!-- Example 1: Playful Purple theme with Grid layout -->
<body class="layout-grid theme-playful spacing-standard">

<!-- Example 2: Warm Sunset theme with Single Column layout -->
<body class="layout-single-column theme-sunset spacing-spacious">

<!-- Example 3: Cool Ocean theme with Left Sidebar layout -->
<body class="layout-sidebar-left theme-ocean spacing-compact">

2. Selectable Theme Options

🌲 theme-nature (Default) Forest greens, mint badges, clean sans-serif typography. Perfect for wildlife & woodland animals.
🌊 theme-ocean Deep blues, cyan highlights, soft sky backgrounds. Great for aquatic life, marine pets, and birds.
🌅 theme-sunset Warm terracottas, amber accents, sandy desert tones. Ideal for reptiles, cats, and safari animals.
🎈 theme-playful Vibrant purples, rounded corners, bubbly fonts. Great for energetic puppies, kittens, and fun pets.
🌙 theme-dark Sleek dark slate background with glowing neon accents. Perfect for nocturnal animals and modern aesthetics.

3. Using & Adapting the Navigation Bar (Optional)

The template includes an optional navigation bar in the header. It uses simple anchor links that jump down to each section on the page:

<!-- In the header: links with href="#..." -->
<nav class="header-nav" aria-label="Page Sections">
  <a href="#about" class="nav-link">About</a>
  <a href="#gallery" class="nav-link">Photos</a>
  <a href="#videos" class="nav-link">Videos</a>
  <a href="#facts" class="nav-link">Care Guide</a>
</nav>

<!-- In the page: sections with matching id="..." -->
<section id="about">...</section>
<section id="gallery">...</section>
<section id="videos">...</section>
<section id="facts">...</section>
How to Adapt or Remove Navigation:
  • Change link names: Simply change the text between <a> and </a> (e.g. change Photos to Dragon Gallery).
  • Add a new link: Add a new <a href="#new-section" class="nav-link">Title</a> and give your target section id="new-section".
  • Optional: If you want a simpler page without top navigation links, you can safely delete the whole <nav class="header-nav">...</nav> block!

4. Embedding Videos with Native Controls (AC 4.2 & 4.3)

HTML5 makes embedding videos simple. Always include the controls attribute so users can play, pause, seek, and adjust sound:

<video controls poster="images/my-preview.jpg" class="video-player">
  <!-- 1. Your exported local video -->
  <source src="videos/my-pet-clip.mp4" type="video/mp4">
  
  <!-- 2. Optional online test video (for testing playback) -->
  <source src="https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4" type="video/mp4">
  
  Your browser does not support HTML5 video.
</video>
Key Video Attributes to Know:
  • controls: Displays the play/pause button, progress seek bar, volume slider, and fullscreen button.
  • poster="...": Shows a thumbnail cover image before the visitor hits play.
  • source src="...": Tells the browser where the video file is saved on disk.

5. Creating Click-to-Reveal Info Cards (Accordion)

HTML5 provides built-in expandable sections using <details> and <summary>. No JavaScript required!

<details class="accordion-item">
  <summary class="accordion-summary">
    <span class="summary-icon">🥗</span>
    <span class="summary-title">Feeding & Nutrition Guide</span>
    <span class="chevron">▼</span>
  </summary>
  <div class="accordion-body">
    <p>Adult dogs eat twice daily with access to fresh water...</p>
  </div>
</details>
