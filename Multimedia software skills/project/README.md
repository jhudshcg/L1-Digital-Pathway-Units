# Project Workspace: Pet & Animal Showcase Webpage

Welcome to your project workspace! This folder is where you will build, customize, and save your finished single-page pet/animal multimedia website.

---

## 📁 Getting Started

1. **Copy starter files:** Copy all files and folders from `../template/` into this `project/` folder:
   - `index.html`
   - `style.css`
   - `images/` folder
   - `videos/` folder

2. **Open in VS Code:** Open this `project/` folder in VS Code.

3. **Live Server / Preview:** Right-click `index.html` and select **Open with Live Server** (or open it directly in Microsoft Edge / Chrome) to see your webpage update as you work.

---

## 🎨 Customisation Quick Checklist

- [ ] **Step 1:** Choose your pet or animal topic.
- [ ] **Step 2:** Choose your theme and layout in `index.html` on the `<body>` tag:
  - Layouts: `layout-grid`, `layout-single-column`, `layout-sidebar-left`
  - Themes: `theme-forest`, `theme-ocean`, `theme-sunset`, `theme-playful`, `theme-dark`
  - Spacing: `spacing-compact`, `spacing-standard`, `spacing-spacious`
- [ ] **Step 3:** Source, crop, and save your 4 images into the `images/` folder.
- [ ] **Step 4:** Record/trim your 2 videos and export them into the `videos/` folder.
- [ ] **Step 5:** Update headings, descriptions, facts, and media captions in `index.html`.
- [ ] **Step 6:** Commit your progress regularly using Git in the VS Code Source Control panel!
