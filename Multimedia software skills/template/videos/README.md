# Videos Directory

Save your exported, web-optimized `.mp4` video files here:
- `action-clip.mp4` (e.g. playing, running, foraging, or behavior clip)
- `pet-intro.mp4` (e.g. self-recorded presentation, trick, or daily routine clip)

### Testing Before Export:
The starter template contains fallback online video links so you can test your video player controls in the browser right away before adding your own local video files.
