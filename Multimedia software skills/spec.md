# Multimedia Software Skills R/505/1688

Webpage with images and video.

GLH: 27

**Theme:** 

Make a multi-media webpage for a pet or animal of your choice. It should be entertaining and informative, with a clear layout, accessible and responsive design, and suitable images and videos. 

**Project structure:**

1 HTML file, 1 CSS file, 1 image folder, 1 video folder.

CSS file is provided with a minimal set of responsive and accessible styles, structured and commented in a clear and simple way. Students should be able to select different classes for elements to change the layout, look and feel of the webpage, without needing to edit the CSS file. But some activities/tasks should involve editing the CSS file for making minor edits to change colours, fonts, images and spacing.

Students must: 

research and plan the content of the page, based on the chosen pet/animal.

collect images/videos in a suitable format and resolution for the webpage, and evidence this research in their project booklet.

The HTML page should be provided initially as a template with the basic structure and some clear place holder content, which students will edit to implement their own design choices and content.

The chosen images could show the pet/animal in different contexts, such as in its natural habitat, interacting with humans or other animals, or engaging in specific behaviors. 

The videos could show the pet/animal in action, such as playing, eating, or performing tricks. One of the videos could be recorded (and edited) by the student on their phone, either of their own or a friend's pet, of of themselves talking about the pet/animal. This video should be suitably edited for length and content, and should be appropriate for the target audience.

Video editing can be on the mobile phone used to record it, or on something like MS Clipchamp after transferring the video to a computer. Students should be able to evidence their video editing in their project booklet, with a short description and screenshot(s). This could be as simple as trimming the start and end of the video, or adding a title screen, or adding a short caption to the video. It could also include more ambitious edits involving different tracks, transitions, colour grading and effects, but this is NOT a requirement.

All media should be stored locally to the site.

Image editing can be done on a mobile device app, or computer using something like Photoshop, paint, Photos or other suitable software. Students should be able to evidence their image editing in their project booklet, with a short description and screenshot(s). This should remain simple, as there is a separate unit for Imaging Software that will cover more advanced image editing skills.

**Project requirements:**

1 page about the pet/animal of choice, containing a minimum of 4 relevant images and 2 videos, with matching description and additional text information. The page must have a clear layout, be accessible and have a responsive design.

Images/videos must be cropped/trimmed and sized appropriately for the webpage, and should be optimized for web use (compressed to reduce file size without losing quality). Any file format commonly supported by web browsers is acceptable, but students should be able to justify their choice of file format in their project booklet.

**Resource set:** 

template HTML and CSS files, with a minimal set of responsive and accessible styles, structured and commented in a clear and simple way.

guide HTML file to demonstrate how to add and alter image, video to a page.
guide HTML file for making interactive elements like links and click to reveal descriptions, using the provided CSS classes, not JS.

the project booklet doc should contain some useful links for researching pets and animals.

## Booklet tasks/activities with assessment criteria mapping

The sequence of tasks and activities in the student project booklet, the student evidence required, and the assessment criteria mapping:

### Section 1: Planning & Information Gathering
* **Task 1: Topic Selection & Purpose (AC 1.1, 1.2)**
  - *Activity:* Select a pet or animal topic. State why you chose it, identify 3 key facts visitors will learn, and choose the target audience (e.g. children, pet owners, general public).
  - *Student Evidence:* 
    1. Short prompt: *"What pet or animal have you chosen, and why?"* (Text box)
    2. Short prompt: *"What are the 3 main things visitors will learn or see on your page?"* (3-point list)
    3. Target audience selector table (Audience type + 1 sentence on what they want to see).
  - *Criteria Mapping:* **AC 1.1, AC 1.2**

* **Task 2: Media Asset Specification & Research (AC 1.3, 1.4)**
  - *Activity:* Choose what each of your 4 images and 2 videos will show using the prompt ideas bank (or your own ideas), write a short description, explain why you chose it, and record any research links used. *(Note: All chosen images and videos must be college-appropriate and family-friendly).*
  - *Prompt Ideas Bank (15 visual concepts):*
    - Natural Habitat / Environment
    - Feeding / Favourite Food
    - Hunting / Foraging in the Wild
    - Fighting / Defense / Territory Display
    - Mating Habits / Courtship Displays (family-friendly, e.g. bird songs, dances, nest building)
    - Close-up Portrait / Face
    - Action / Running / Playing
    - Resting / Sleeping
    - Baby / Young Animal
    - Unique Physical Feature (e.g. claws, fur, eyes)
    - Interacting with Humans / Handlers
    - Performing a Trick / Skill
    - Health & Grooming / Daily Care
    - Funny / Quirky Behavior
    - Talking / Presenter Intro Video
  - *Student Evidence:* 6-row Media Specification Table (Asset Name e.g. Image 1–4, Video 1–2; Chosen Concept from bank/own; Content Description; Reason for Choice; Research / Reference URL).
  - *Criteria Mapping:* **AC 1.3, AC 1.4**

* **Task 3: Page Layout & Concept Map (AC 1.1)**
  - *Activity:* Plan the webpage layout and content sections using a 5-point concept cross map (`layout-5-textbox-cross`), then sketch or insert a wireframe layout diagram.
  - *Student Evidence:* 
    1. 5-box concept cross: Header/Hero, About & Fun Facts, Photo Gallery, Video Showcase, Care & Info/Footer.
    2. Wireframe layout diagram / sketch box.
  - *Criteria Mapping:* **AC 1.1**

* **Task 4: Copyright, Licensing & Sourcing Log (AC 1.4)**
  - *Activity:* Source royalty-free media assets and log source URLs, creators, and license permissions. Explain why copyright rules must be followed.
  - *Student Evidence:* 
    1. 6-row Sourcing Log (Local filename, Source URL / Creator, Asset Type, License Type).
    2. Short prompt: *"Why is it important to check copyright before using images and videos from the web?"* (Text box).
  - *Criteria Mapping:* **AC 1.4**

---

### Section 2: Capturing, Inputting & File Formats
* **Task 5: Input Devices & Recording Media (AC 2.1, 2.2)**
  - *Activity:* Use keyboard/mouse to write text descriptions and use a smartphone, camera, or webcam/microphone to capture original video footage or voiceover.
  - *Student Evidence:* 
    1. Input devices log table (Device used, Input type, How content was transferred/entered).
    2. Screenshot or photo of video recording / camera footage / audio recording in progress.
  - *Criteria Mapping:* **AC 2.1, AC 2.2**

* **Task 6: File Formats & Storage Media (AC 2.3, 2.4)**
  - *Activity:* Identify web-friendly file formats (`.html`, `.css`, `.jpg`/`.webp`, `.mp4`) and explain why they are suitable for fast page loading and browser playback.
  - *Student Evidence:* 4-row File Formats Table (Format, File Type, Why it is used for web pages, Storage location).
  - *Criteria Mapping:* **AC 2.3, AC 2.4**

---

### Section 3: Editing, Manipulating & Building the Webpage
* **Task 7: Image Editing & Optimization (AC 3.1, 3.2)**
  - *Activity:* Crop, resize, and compress your 4 images (using MS Photos, Paint, Canva, or Squoosh) so they fit the page layout and load quickly.
  - *Student Evidence:* 
    1. 4-row Image Optimization Log (Original size/dimensions vs Edited size/dimensions and edit action taken).
    2. Screenshot of image editing/cropping software in action.
  - *Criteria Mapping:* **AC 3.1, AC 3.2**

* **Task 8: Video Editing & Trimming (AC 3.1, 3.2)**
  - *Activity:* Trim your 2 video clips using video editing software (e.g. MS Clipchamp or mobile editor) to cut unwanted footage, adjust sound, and add a title card or caption.
  - *Student Evidence:* 
    1. Video editing log table (Clip name, Trim start/end times, Titles/captions added, Final exported `.mp4` size).
    2. Screenshot of the video editing timeline/export screen in Clipchamp or mobile editor.
  - *Criteria Mapping:* **AC 3.1, AC 3.2**

* **Task 9: Webpage Assembly & Styling (AC 2.2, 3.1)**
  - *Activity:* Combine text, edited images (`<img>`), and videos (`<video controls>`) in `index.html`, and choose CSS theme classes on `<body>` (e.g. colour scheme, typography, layout grid).
  - *Student Evidence:* 
    1. Styling record table (Theme chosen, Layout class selected, Accent colour).
    2. Full-page screenshot of the finished, styled webpage in a browser.
  - *Criteria Mapping:* **AC 2.2, AC 3.1**

---

### Section 4: Display, Playback Control & Testing
* **Task 10: Screen Sizes & Display Devices (AC 4.1, 4.4)**
  - *Activity:* Identify target display devices (desktop, tablet, mobile) and test how your webpage adjusts to different screen widths using browser DevTools or window resizing.
  - *Student Evidence:* 
    1. Display devices note (Desktop monitor vs Smartphone screen differences).
    2. Side-by-side screenshots showing the webpage in Desktop view vs Mobile view.
  - *Criteria Mapping:* **AC 4.1, AC 4.4**

* **Task 11: Navigation & Video Playback Controls (AC 4.2, 4.3)**
  - *Activity:* Test page navigation (anchor links / click-to-reveal cards) and test HTML5 video playback controls (play, pause, volume/mute, seek bar, fullscreen).
  - *Student Evidence:* 
    1. Playback controls checklist table (Play/Pause, Seek, Volume/Mute, Fullscreen - Pass/Fail).
    2. Screenshot showing video actively playing in the browser with visible on-screen controls.
  - *Criteria Mapping:* **AC 4.2, AC 4.3**

* **Task 12: File Management & Relative Links (AC 2.5, 2.6)**
  - *Activity:* Organize all files into structured folders (`images/`, `videos/`, root `.html` and `.css`), and verify that relative file paths load all media correctly.
  - *Student Evidence:* Screenshot of the clean folder structure in File Explorer / VS Code; short 2-line explanation of how relative file paths keep links working.
  - *Criteria Mapping:* **AC 2.5, AC 2.6**

* **Task 13: Testing & Making Corrections (AC 3.3)**
  - *Activity:* Perform a final quality check across the webpage (broken links, video playback, text spelling, image alignment) and record any fixes made.
  - *Student Evidence:* 5-row Test & Corrections Table (Item checked, Problem found, Correction made, Pass status).
  - *Criteria Mapping:* **AC 3.3**
